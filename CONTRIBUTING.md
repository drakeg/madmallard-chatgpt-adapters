# Contributing

Add new integrations under `adapters/<slug>/ADAPTER.md`. Each adapter should include purpose, source/attribution, invocation, behavior, tool and permission requirements, limitations, and validation.

If a local installer is necessary, put it under `scripts/`. Never overwrite an existing user skill or package secrets in the repository. Keep commits focused, add or adjust automation checks, and open a reviewable PR.

Commercialization goals inform priority but are not blockers for authorized software development.
