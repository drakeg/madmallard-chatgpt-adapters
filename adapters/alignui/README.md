# Mad Mallard AlignUI

Original ChatGPT adapter for [AlignUI](https://www.alignui.com/), with [SKILL.md](SKILL.md), [source and license references](references/sources.md) and [evaluation fixtures](evals.json).

**License:** MIT for Base Components; separate paid license for Pro. Free Base Components may be used under MIT with license notice; Pro assets require separate authorization.

Use independently when the project already uses or is evaluating AlignUI; Creative Studio compares it against HeroUI, Ant Design, other existing libraries and the product's approved identity before selection. Instructions alone do not install runtime packages or prove accessibility.
