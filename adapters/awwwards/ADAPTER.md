# Awwwards adapter

Source: https://github.com/Gsta/awwwards-mcp

**Purpose:** MCP server for visual web references and authorized motion analysis.

Install with `python3 scripts/install_design_toolkit.py --tools awwwards --with-deps` on an authorized system. Use the matching [reusable GitHub Action](../../actions/setup-awwwards/action.yml) in CI.

The installer generates MCP configuration for MCP-capable tools. It does not connect these tools to every ChatGPT chat or guarantee free access to external sites. Respect third-party site terms, screenshots and original asset copyrights. Verify locally before claiming results.
