# Mad Mallard daisyUI

Original ChatGPT adapter for [daisyUI](https://daisyui.com/), with [SKILL.md](SKILL.md), [source and license references](references/sources.md) and [evaluation fixtures](evals.json).

**License:** MIT. The open-source daisyUI library is MIT; commercial templates or assets are outside this adapter.

Use independently when the project already uses or is evaluating daisyUI; Creative Studio compares it against HeroUI, Ant Design, other existing libraries and the product's approved identity before selection. Instructions alone do not install runtime packages or prove accessibility.
