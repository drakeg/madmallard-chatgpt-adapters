# Design Scope adapter

Source: https://github.com/unfoldingdimensions/design-scope-mcp

**Purpose:** MCP server for local color, typography, and interaction reference cards.

Install with `python3 scripts/install_design_toolkit.py --tools design-scope --with-deps` on an authorized system. Use the matching [reusable GitHub Action](../../actions/setup-design-scope/action.yml) in CI.

The installer generates MCP configuration for MCP-capable tools. It does not connect these tools to every ChatGPT chat or guarantee free access to external sites. Respect third-party site terms, screenshots and original asset copyrights. Verify locally before claiming results.
