# Flowscope adapter

Source: https://github.com/0050piyush/flowscope

**Purpose:** Local UI and flow gallery; not an MCP server.

Install with `python3 scripts/install_design_toolkit.py --tools flowscope --with-deps` on an authorized system. Use the matching [reusable GitHub Action](../../actions/setup-flowscope/action.yml) in CI.

The installer generates MCP configuration for MCP-capable tools. It does not connect these tools to every ChatGPT chat or guarantee free access to external sites. Respect third-party site terms, screenshots and original asset copyrights. Verify locally before claiming results.
