Original ChatGPT router for research, UX strategy, design systems, forms, accessibility, critique, usability testing and handoff. The upstream Claude Code slash commands, agent hooks and Gemini CLI extensions are not automatically installed.

Example: Use Owl Designer to review my quote form for accessible input labels, validation and error recovery; produce a QA checklist based on actual evidence.

Standalone plugin is maintained independently. Creative Studio uses its targeted UX methodologies while Taste leads visual direction, MengTo leads specialist frontend work, and Algorithmic Art stays optional.
