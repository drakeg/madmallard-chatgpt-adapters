# Screenshots adapter

Source: https://github.com/joesteinkamp/screenshots-design-inspiration

**Purpose:** MCP server for real UI screenshots and design-pattern searches.

Install with `python3 scripts/install_design_toolkit.py --tools screenshots --with-deps` on an authorized system. Use the matching [reusable GitHub Action](../../actions/setup-screenshots/action.yml) in CI.

The installer generates MCP configuration for MCP-capable tools. It does not connect these tools to every ChatGPT chat or guarantee free access to external sites. Respect third-party site terms, screenshots and original asset copyrights. Verify locally before claiming results.
