# Mad Mallard Scroll Craft — standalone ChatGPT skill

Original ChatGPT adaptation of [nateherkai/scroll-craft](https://github.com/nateherkai/scroll-craft) (MIT).

- [Skill](SKILL.md)
- [ChatGPT and coding-agent adapter](ADAPTER.md)
- [Compatibility assessment](ASSESSMENT.md)
- [Evaluation prompts](evals.json)

Use for premium, experiential scroll-driven websites with a deliberately selected page grammar, emotional peak, interactive signature moment and verified static/mobile/reduced-motion alternatives.

The skill gives ChatGPT instructions; the upstream engine and browser toolchain are separate, available through the [cross-platform installer](../../scripts/install_design_toolkit.py) or the existing [setup action](../../actions/setup-scroll-craft/action.yml). This skill must not be imposed on dashboards or transactional pages.
